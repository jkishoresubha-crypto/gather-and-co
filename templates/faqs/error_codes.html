HTTP status codes vs. application codes

HTTP status codes (400–503) are a web standard. Every response from any website carries one, and browsers and tools understand them.

Application codes are specific to Gather & Co. 4600 AI_ASSISTANT_UNAVAILABLE is our own code: it is not an HTTP status. It appears inside the chat when the AI service cannot answer, while the page itself still loads normally (HTTP 200).
